# Asset attribution

`/docs` is reserved for essential, durable project concepts and processes. This page records the provenance and usage boundaries of the brand mark the website uses.

## JG mark

`website/public/favicon.svg` is an unchanged copy of the `JG/` monogram from `jesusgraterol.dev/public/favicon.svg`. The header logo redraws the same monogram with the site's theme tokens so it reads in both color schemes. The open-graph image redraws it with the favicon's own colors. Do not alter its letterforms or the accent slash.
